# CyberSecurityFundmentals
Python Codes
CyberSecurity Fundamentals
A collection of educational scripts and tools designed to demonstrate core concepts in cybersecurity.

Note: This repository is for learning and ethical purposes only. Use responsibly and in authorized environments.

🛠️ Tools Included
Based on the project structure, this directory contains the following cybersecurity-related utilities:

Hash Cracker
A basic script to demonstrate how hashing and brute-force or dictionary-based hash cracking works (supports common algorithms like MD5, SHA1, etc.).
Password Strength Checker
Evaluates password complexity based on length, character variety, and common patterns.
Simple Port Scanner
Scans a target host for open ports using basic socket programming (not a replacement for tools like Nmap—meant for educational insight).
File Integrity Checker
Uses cryptographic hashes (e.g., SHA-256) to monitor and detect changes in critical files.
Basic Encryption/Decryption Tool
Demonstrates symmetric encryption using algorithms like AES (via Python’s cryptography library) for secure data handling.
Metadata Remover (for Privacy)
Strips EXIF and other metadata from common file types (e.g., images) to protect user privacy.
⚠️ Disclaimer: These tools are simplified examples. They are not production-grade and should not be used in real-world security operations without thorough review and enhancement.
